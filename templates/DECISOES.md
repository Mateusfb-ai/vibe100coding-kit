# DECISÕES DO CÓDIGO

> O código de produto não carrega comentário. O porquê de cada decisão não óbvia vive aqui, com data, para a próxima sessão não reabrir o que já foi medido.
>
> Formato: uma entrada por decisão, mais recente no topo. Número com data é histórico, não estado.

## AAAA-MM-DD — <título curto da decisão>
- **Onde:** `caminho/arquivo.ext` (função ou trecho)
- **O que:** <a decisão em uma frase>
- **Por quê:** <a medição ou o defeito que a originou>
- **Gate:** `npm run gate:<nome>` (ou "sem gate ainda", que é o estado que já falhou)
- **Não reabrir a menos que:** <o que teria de mudar para a decisão voltar à mesa>
