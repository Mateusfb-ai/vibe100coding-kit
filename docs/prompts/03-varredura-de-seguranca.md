# Prompt: varredura de segurança por classe

Método que achou um bypass integral de assinatura escondido atrás de um gate com premissa errada.

```
Varredura de segurança, SOMENTE LEITURA. Despache um subagente por
(componente × classe de defeito): rotas de dado alheio × IDOR; upload × teto de
tamanho/pixels; formulários com segredo × método/URL; jobs × reentrega tardia;
armazenamento × dado pessoal sem prazo; cache/ETag × guarda antes do 304.

Cada subagente recebe a lista de invariantes JÁ PROVADAS (para não reportar o
que é desenho) e devolve só achado com PoC reproduzível. Dois subagentes
chegando ao mesmo achado por caminhos diferentes = confirmado.

Para cada achado: conserto mínimo + gate com mutação. Se um gate existente
protegia o furo com premissa errada, ele muda de lado com o motivo reescrito,
nunca é apagado.
```
